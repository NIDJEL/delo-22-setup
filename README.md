# Локальная установка ДЕЛО 22.2

Для Windows 10 22H2 и Windows 11 x64. Нужны права администратора, интернет и минимум 8 ГБ свободного места.

1. Скачайте `Delo-Setup.exe` со страницы релиза GitHub и положите его в доступную для записи папку.
2. Запустите EXE и подтвердите системный запрос Windows, если он появится. В меню выберите `1. Установить или продолжить`. Этапы загрузки и установки выводятся в консоль автоматически. Если компонент запросит перезагрузку, установка продолжится после следующего входа в тот же профиль Windows.
3. Если установка прервалась, снова выберите пункт 1. Установщик проверит SQL Server, базу, настольный клиент и сайт, использует сохранённые загрузки и пропустит завершённые этапы.
4. Рядом с EXE появятся `Дело.lnk` и `Дело - вход.txt`. В TXT указаны логин `LAB22`, пароль этого ПК и адрес веб‑версии. Открытие и восстановление TXT доступны через пункт 3.
5. Пункт `4. Запустить ДЕЛО-Web` запускает локальные службы и пулы IIS учебной установки, проверяет ответ сервера и открывает страницу входа. [ДЕЛО-Web](http://127.0.0.1:8765/LAB22/)

Установщик скачивает и проверяет комплект ЭОС от 27.05.2025, настраивает Microsoft SQL Server 2019 Express Advanced, создаёт отдельную демонстрационную базу, устанавливает настольный клиент, IIS, расширения IIS и нужные версии .NET. Сайт и SQL Server доступны только с этого компьютера.

Настольные модули, включая «Документы», «Пользователи» и «Справочники», устанавливаются до настройки веб-сайта. Если веб-установка прервалась, настольные модули доступны через ярлык. Пункт 1 продолжит настройку сайта.

Если на ПК уже настроено ДЕЛО с собственной базой, установщик создаёт рядом с EXE ярлык к существующим модулям. Для входа используются данные этой базы. Автоматическое сохранение пароля в TXT доступно для учебной базы, созданной установщиком.

Для веб‑версии нужен IIS. Если компонент отсутствует в образе Windows, установщик завершит настройку настольных модулей и запишет причину в журнал.

В SQL Server Express служба SQL Server Agent недоступна. Установщик выполняет штатную обработку накопившейся очереди событий ДЕЛО при установке и через пункт 4. [Возможности выпусков SQL Server 2019](https://learn.microsoft.com/en-us/sql/sql-server/editions-and-components-of-sql-server-2019)

Настольное ДЕЛО требует короткий формат даты `dd/MM/yyyy`. При необходимости установщик задаёт его в текущем профиле Windows. При удалении прежнее значение восстанавливается, если формат с тех пор не меняли.

Установщик запускает мастера ЭОС на отдельном рабочем столе Windows, сам заполняет формы и закрывает завершённые окна. Режим `Delo-Setup.exe -ManualWizard` доступен для диагностики с видимыми окнами.

## Перенос базы на другой компьютер

1. На исходном ПК откройте обновлённый `Delo-Setup.exe` и выберите `5. Экспортировать базу на другой ПК`. Рядом с EXE появится файл `Дело-LAB22_DB-….delo`.
2. Перенесите `Delo-Setup.exe` и файл `.delo` на другой ПК. Если там ещё нет учебного ДЕЛО 22.2, установите его через пункт 1. Дождитесь завершения установки.
3. На новом ПК закройте модули ДЕЛО и вкладки ДЕЛО-Web. В установщике выберите `6. Импортировать базу с другого ПК`, откройте файл `.delo` и введите `ИМПОРТ`.
4. Откройте ДЕЛО обычным ярлыком. Для входа под `LAB22` используйте пароль нового ПК из пункта 3. Пароли перенесённых пользователей ДЕЛО сохраняются.

Перенос рассчитан на учебную установку с базой `LAB22_DB` в локальном SQL Server 2019. В копию входят карточки, справочники, пользователи и вложения, хранящиеся в базе. Для вложений во внешнем хранилище нужен отдельный перенос. Храните файл `.delo` как резервную копию с вашими документами и данными учётных записей.

Установщик проверяет резервную копию, восстанавливает её отдельно и проверяет вход `LAB22`. После переключения предыдущая база остаётся в SQL Server под именем `LAB22_DB_before_…`. Имя выводится в консоли и журнале.

Для запуска с указанным файлом доступны параметры `-ExportDatabase -TransferPath "C:\Копии\Дело.delo"` и `-ImportDatabase -TransferPath "C:\Копии\Дело.delo"`. Импорт запрашивает подтверждение в консоли.

## Удаление

Откройте EXE и выберите `2. Удалить ДЕЛО`. Если найдено несколько локальных установок, выберите нужную базу. Подтвердите командой, указанной в меню. Для `LAB22_DB` это `УДАЛИТЬ`, для прежней базы `IK342_DB` — `УДАЛИТЬ IK342_DB`.

Удаление убирает выбранную базу вместе с её документами, привязанные к ней компоненты ДЕЛО и файлы установки. Экземпляр SQL Server удаляется, если в нём больше нет пользовательских баз. При удалении единственной установки также очищается кэш загрузок. Тем же EXE можно заново загрузить и установить ДЕЛО через пункт 1. Если Windows запросит перезагрузку во время удаления, после входа снова выберите пункт 2.

## Источники и диагностика

- Установщик скачивает оригинальный архив ДЕЛО из релиза v0.1.0 на GitHub. Если зеркало недоступно, используется ссылка ЭОС на Яндекс Диск. Для обоих источников проверяется одна контрольная сумма SHA‑256 выпуска от 27.05.2025. [Дистрибутивы ЭОС](https://eos.ru/eos_products/eos_delo/distributiv-delo/)
- Зависимости скачиваются с серверов Microsoft. Установщик проверяет их цифровые подписи. [SQL Server 2019 Express](https://www.microsoft.com/en-us/download/details.aspx?id=108837)
- `Delo-Setup.exe -Check` проверяет Windows и свободное место. `-DownloadOnly` загружает и проверяет файлы. `-SourceFolder "C:\Дистрибутивы\Дело"` использует распакованную копию той же сборки. `-ArchiveUrl` принимает HTTPS-адрес архива с тем же SHA‑256.
- Журнал выполнения хранится в `%LOCALAPPDATA%\Delo22Lab-Setup\setup.log`.

## Сборка

На Windows x64 запустите `Build-Exe.ps1` через Windows PowerShell. Скрипт компилирует EXE средствами .NET Framework и встраивает сценарии установки и список контрольных сумм.
