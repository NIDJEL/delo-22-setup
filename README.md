# Локальная установка ДЕЛО 22.2

Установщик для учебной работы на Windows 10 22H2 и Windows 11 x64. Нужны права администратора, подключение к интернету и минимум 8 ГБ свободного места.

1. Скачайте `Delo-22.2-Setup.zip` со страницы релиза GitHub и распакуйте архив целиком.
2. Запустите `Start-Delo-Setup.cmd`, подтвердите запрос Windows и введите `YES`, если согласны с условиями устанавливаемых компонентов.
3. Если Windows запросит перезагрузку, перезагрузите компьютер и откройте тот же файл запуска. Загрузки и завершённые этапы будут использованы повторно.
4. После установки откроется [ДЕЛО-Web](http://127.0.0.1:8765/LAB22/). Логин администратора `LAB22`. Пароль можно скопировать в конце установки или командой `Start-Delo-Setup.cmd -CopyPassword` из того же профиля Windows.

Установщик загружает и проверяет комплект ЭОС от 27.05.2025, устанавливает Microsoft SQL Server 2019 Express Advanced, IIS, расширения IIS и среду .NET, создаёт отдельную демонстрационную базу и устанавливает настольный клиент. База и веб-сайт предназначены для доступа с этого компьютера. Настройки ранее установленных клиентов ДЕЛО сохраняются.

Штатные мастера ЭОС могут появляться на экране. Оставьте их открытыми. Если автоматическое заполнение остановилось, установщик покажет параметры текущего этапа. Для ручного прохождения обоих мастеров используйте `Start-Delo-Setup.cmd -ManualWizard`.

Если PowerShell помечает файлы как скачанные, проверьте источник архива и свойство «Разблокировать» на ZIP перед распаковкой. Установщик использует политику RemoteSigned для своего процесса.

## Источники и проверка

- Установщик и архив ДЕЛО находятся в релизе GitHub. Если зеркало недоступно, используется ссылка ЭОС на Яндекс Диск. Для обоих источников проверяется одна контрольная сумма SHA‑256 выпуска от 27.05.2025. [Дистрибутивы ЭОС](https://eos.ru/eos_products/eos_delo/distributiv-delo/)
- Зависимости скачиваются с серверов Microsoft. Проверяется цифровая подпись каждого установщика. [SQL Server 2019 Express](https://www.microsoft.com/en-us/download/details.aspx?id=108837)
- `Start-Delo-Setup.cmd -Check` проверяет Windows и свободное место. `Start-Delo-Setup.cmd -DownloadOnly` загружает и проверяет файлы без установки. `-SourceFolder "C:\Путь\К\ДЕЛО"` использует уже распакованную копию той же сборки. `-ArchiveUrl` принимает HTTPS-адрес зеркала с тем же SHA‑256.
- Журнал выполнения хранится в `%LOCALAPPDATA%\Delo22Lab-Setup\setup.log`. Для SQL Server журнал Microsoft находится в каталоге `SQL Server\150\Setup Bootstrap\Log` под `%ProgramFiles%\Microsoft SQL Server`.
